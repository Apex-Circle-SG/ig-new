# Programmatic SEO

No salary pages or programmatic batch has been published. A URL must represent a unique city/occupation with validated wages, source versions, usable calculator functionality and comparisons. Search demand alone never qualifies a page.

The future workflow is DRAFT → QUALITY_CHECK → preview → explicit batch approval → PUBLISHED → MONITORING. Database constraints retain quality thresholds and approval identity/time. The quality gate in `packages/seo` provides a deterministic initial evaluation; it does not publish anything.

Required metadata: unique title/description, canonical host, meaningful server-rendered H1/content, valid entity/schema, source attribution, updated date, internal links and accessible interaction. Similar entities need stable canonical keys; filters default noindex. Editorial articles require real authors/reviewers.

Start with 200–500 qualifying pages only when data permit. Import real GSC impressions/clicks and first-party engagement before scaling. No GSC credentials currently exist. Retirement uses only reviewed equivalent301 mappings; otherwise410. Migration registry remains inactive until complete backup and review.
