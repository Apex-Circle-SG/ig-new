# Ask Ginie catalog copilot

23 October 2026. Ask Ginie searches the current Cloudflare opportunity catalog before using general AI. It retrieves remote roles and open-source rewards using bounded keyword, listed-location, employment-arrangement and source-listed-pay filters. Earning methods, ideas and platform profiles are searched and ranked from their public catalog fields. It displays up to five real records with internal detail links and original sources. Methods remain guides, and ideas remain unvalidated experiments; neither is presented as an available paid assignment. Job location text does not prove eligibility.

Catalog responses are constructed locally from actual records, not generated by Datadog. Unknown, closed or expired job records cannot become displayed opportunities. Outages and empty matches produce explicit messages and directory links. Fetches use the existing first-party catalog client with its bounded timeout and up to 120-second cache. Monetary values detected in the question are omitted before deriving public search terms. Search filters can appear in catalog-service request records; confidential information does not belong in this public search.

The browser sends the last result's bounded filter state for refinements such as “Only in Singapore” and “What about contract roles?”. Fresh searches reset filters; “Show me more” retrieves a subsequent five-record page. The directory link opens the full matching directory at its first page, whose page size differs from chat. Location filtering matches source text; country aliases, ambiguous requests, negative filters and arbitrary salary/experience/degree requirements are not a full eligibility engine. Numeric compensation thresholds are not supported. Review each employer's requirements.

General AI follow-ups can use up to two recent question/answer exchanges (each field at most 1,200 characters). Identifiable turns are excluded and detected financial values are minimized. All transcript content is untrusted context, never system authority or verified sources. Server-configured secret values remain blocked at the provider boundary. Conversation and answers are never written to the application state/cache/logs or analytics. The browser retains up to six exchanges in the current tab; “Start new chat” clears them. Datadog can retain minimized general requests and answers. The Ask page, privacy policy and AI disclosure explain this before general submissions.

The global 60-second wait after a successful AI execution is removed. A durable failed/ambiguous-request backoff remains, along with the exclusive execution lock, per-address/global request limits, timeout/cancellation and run reservations. The existing 20 runs/day and 120 runs/month stay unchanged. These are execution limits, not a verified dollar or provider AI-credit balance. No budget ledger was reset. Catalog searches do not consume Datadog executions and remain usable while a general AI request is busy or budget-limited. The public-question authorization and existing remote agent settings remain unchanged.

Supported arithmetic still uses deterministic calculators. Source-grounded explanations still use reviewed passages and the existing public-only selection cache. Unmatched general answers remain explicitly labelled as unverified and do not acquire invented citations. There is no general web crawler, account access, application submission, saved personal profile or cross-device memory in this release.

Verification: unit coverage exercises real record reconstruction, empty/outage responses, closed/expired records, filter persistence/reset/paging, request bounds, context minimization and existing provider budget/concurrency/failure protections. Browser checks exercise real catalog search, creative methods, idea links, responsive accessibility, bounded chat context and advertising/analytics exclusion. Release and live receipts are in `docs/verification/ask-copilot-release.json`.
