# Page quality

The gate treats critical failures as blockers, regardless of score. A candidate needs a unique canonical entity, complete critical fields, validated sources, functional interaction, comparison context, metadata/schema, internal links, crawlable HTML, acceptable performance and no near duplicate.

Scores combine data uniqueness/completeness, interaction/context, source quality/freshness, internal links and content uniqueness. Search demand is diagnostic only in the first gate and cannot rescue weak utility. The default score threshold is85/100, configurable by an operator. Passing the gate permits preview, not publication. An explicit reviewed batch approval is still required.

No batch exists in this release. The protected admin/GSC dashboard is a future milestone, not a working feature. Never infer approval from time elapsed or the mere existence of a quality score.
