# Required external evidence and decisions

Updated 2026-09-13. The application now includes source-grounded Ask, six
deterministic finance tools, trust pages, consent-controlled aggregate analytics,
and a read-only WordPress preview pipeline. This document records implementation
and remaining dependencies; it does not certify deployment or external-service
activation. The migration pilot contains **2 of 9,071 inventoried posts**. Its
article previews are noindex and retain their original blog canonicals. There
has been **no WordPress cutover**.
